# HR-Employee-Analytics-Project

HR Employee Analytics Project
Project Overview

This project analyzes HR employee data using SQL and Power BI. The objective is to clean raw employee data, answer key HR business questions using SQL, and develop an interactive dashboard to support workforce analysis and decision-making.

**Tools Used**
MySQL
Power BI
Excel

**Skills Demonstrated**
Data Cleaning
SQL
Data Analysis
Data Visualization
Dashboard Design
KPI Reporting
HR Analytics

**Business Questions**
What is the gender distribution?
What is the race/ethnicity distribution?
What is the employee age distribution?
How many employees work at HQ vs remotely?
What is the average employment length of terminated employees?
How is gender distributed across departments?
What are the most common job titles?
Which department has the highest turnover?
How are employees distributed by state?
How has employee count changed over time?
What is the tenure distribution by department?
